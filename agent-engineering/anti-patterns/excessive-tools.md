# Excessive Tools

## Signal

Every agent sees every tool, increasing selection error, prompt cost, and privilege.

## Why it fails

It increases cost, latency, nondeterminism, and incident surface while obscuring accountability.

## Reject or correct

Scope a small allowlist; use permission-filtered discovery for genuinely large catalogs.

## Required guardrail

A tool description is not authorization.

## Review evidence

Ask for the state model, policy boundary, budget, trace, and a test that demonstrates the guardrail.
