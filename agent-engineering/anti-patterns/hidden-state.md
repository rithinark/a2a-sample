# Hidden State

## Signal

Important plans, decisions, retries, or artifacts exist only in chat history.

## Why it fails

It increases cost, latency, nondeterminism, and incident surface while obscuring accountability.

## Reject or correct

Represent canonical state as typed data with ownership, provenance, lifecycle, and trace links.

## Required guardrail

Prompt summaries are views, not the system of record.

## Review evidence

Ask for the state model, policy boundary, budget, trace, and a test that demonstrates the guardrail.
