# LLM for Deterministic Work

## Signal

A model parses, computes, routes, validates, or orchestrates work that code can decide.

## Why it fails

It increases cost, latency, nondeterminism, and incident surface while obscuring accountability.

## Reject or correct

Move stable logic, policies, calculations, and structured extraction to code; let the model handle semantic uncertainty.

## Required guardrail

Do not hide deterministic policy in prompts.

## Review evidence

Ask for the state model, policy boundary, budget, trace, and a test that demonstrates the guardrail.
