# Multi-Agent by Default

## Signal

Several agents are created without independent ownership or measured benefit.

## Why it fails

It increases cost, latency, nondeterminism, and incident surface while obscuring accountability.

## Reject or correct

Start with one bounded workflow/agent; add workers only for specialization, independent work, or critical-path reduction.

## Required guardrail

Compare against a single-agent baseline.

## Review evidence

Ask for the state model, policy boundary, budget, trace, and a test that demonstrates the guardrail.
