# Retrieval and RAG

Use retrieval when relevant evidence is external, large, changing, or permission-scoped. Begin with structured query/data access when possible; otherwise retrieve, filter/rerank, cite artifact identifiers, and answer only from the selected evidence.

Do not use RAG to compensate for unclear requirements or as a substitute for deterministic lookup. Measure retrieval recall, grounding, permission enforcement, stale-document behavior, empty results, and answer correctness separately.
